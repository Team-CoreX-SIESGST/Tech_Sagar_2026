PARKHI.ai - Technical Summary
PARKHI.ai is a fraud-detection web application designed to help users upload transaction data, process it through an automated fraud analysis pipeline, and view clear, explainable results through an interactive dashboard. The project focuses on transforming noisy transaction CSV files into structured insights by combining a modern web frontend with a Python-based data processing service.
The system is divided into two main parts: a Next.js frontend in client/ and a FastAPI fraud pipeline in mlpy/. The frontend provides the user interface for uploading data, viewing fraud reports, inspecting EDA charts, checking KPI summaries, and exploring suspicious transaction patterns. It also uses internal API routes to communicate with the Python service and display generated outputs in a structured and visually appealing way.
The Python service is responsible for the core fraud workflow. It accepts uploaded CSV files, cleans and standardizes the data, detects suspicious behavioral patterns, engineers fraud-related features, and scores transactions for risk. After scoring, the pipeline generates a fraud report, KPI data, and EDA artifacts such as charts and summary outputs. These outputs are stored locally and then consumed by the frontend for display.
The overall data flow is simple and efficient: a user uploads a CSV file in the dashboard, the frontend forwards it to the fraud pipeline, the pipeline processes the dataset and generates analysis results, and the frontend presents the outcomes in dedicated pages for fraud reporting, EDA, and KPIs. This separation of concerns keeps the system modular and makes it easier to maintain, extend, and deploy.
PARKHI.ai is built with technologies suited for modern data-driven web applications. The frontend uses Next.js, React, TypeScript, and Tailwind CSS, while the backend pipeline uses Python, FastAPI, pandas, scikit-learn, NumPy, LightGBM, and Matplotlib. Together, these tools make it possible to combine interactive visualization with practical machine learning-based fraud analysis.
In summary, PARKHI.ai is a full-stack fraud analytics platform that turns raw transaction data into actionable intelligence. It is designed to support analysts with automated scoring, explainable insights, and a clean dashboard experience for reviewing suspicious activity.
